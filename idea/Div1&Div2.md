# T1 冰封世界

**难度：普及-**

## 题目背景

冰封世界持续了千年，大地被冰层覆盖。春天终于来临，你决定用魔法让所有冰块解冻。

## 题目描述

有 $n$ 块冰块排成一排，第 $i$ 块冰块的初始温度为 $t_i$。你希望所有冰块的温度都不低于 $T$，这样它们就能彻底解冻。

你可以使用两种魔法：

1. **单点加热**：选择一块冰块，将其温度升高 $1$，消耗 $1$ 点魔力。
2. **暖流席卷**：将所有冰块的温度都升高 $1$，消耗 $C$ 点魔力。

两种魔法都可以使用任意多次。请你求出让所有冰块温度都至少为 $T$ 所需的最少魔力。

## 输入格式

第一行三个整数 $n, T, C$。

第二行 $n$ 个整数 $t_1, t_2, \dots, t_n$。

## 输出格式

一个整数，表示最少魔力。

## 样例输入

```
3 5 2
1 3 4
```

## 样例输出

```
6
```

## 样例解释

暖流 $2$ 次消耗 $4$，冰块 $(3,5,6)$；第一块加热 $2$ 次消耗 $2$，总计 $6$。

## 数据范围与提示

- 对于 $20%$ 的数据，$n \le 10$，$T, t_i \le 10$，可以暴力枚举每种魔法的使用次数。
- 对于 $50%$ 的数据，$n \le 1000$，$T, t_i \le 1000$，可以枚举暖流次数并 $(O(n))$ 计算剩余花费。
- 对于 $100%$ 的数据，$1 \le n \le 2 \times 10^5$，$1 \le T, C \le 10^9$，$0 \le t_i \le 10^9$。

## 题解思路

设使用了 $k$ 次暖流席卷，总花费为 $k \cdot C + \sum_{i=1}^{n} \max(0, T - t_i - k)$。

将 $t_i$ 排序后预处理前缀和，即可在 $O(\log n)$ 时间内对任意 $k$ 计算花费。由于花费函数关于 $k$ 是凸函数，可以三分求解，也可以直接枚举 $k$ 的有效范围（$0 \le k \le \max(0, T - \min t_i)$）。总复杂度 $O(n \log n)$。

# T2 废土之下

**难度：普及+/提高-**

## 题目背景

废土之上，辐射风暴正从远方袭来。道路按照编号顺序被辐射依次吞噬，编号越小的道路越早失效。你必须在辐射完全覆盖之前逃到安全区。

## 题目描述

废土中有 $n$ 个聚居点，编号 $1$ 到 $n$，有 $m$ 条双向道路连接它们，道路编号为 $1$ 到 $m$。

辐射风暴的规则是：第 $t$ 天开始时，所有编号不超过 $t$ 的道路会被辐射覆盖，无法通行。也就是说，第 $t$ 天你只能走编号严格大于 $t$ 的道路。

你在第 $1$ 天从聚居点 $1$ 出发，每天可以选择走一条道路（到达另一端），或者留在原地。你需要到达聚居点 $n$（安全区）。求最少需要多少天，若永远无法到达则输出 $-1$。

## 输入格式

第一行两个整数 $n, m$。

接下来 $m$ 行，第 $i$ 行两个整数 $u_i, v_i$，表示编号为 $i$ 的道路连接 $u_i$ 和 $v_i$。

## 输出格式

一个整数，表示最少天数；无法到达输出 $-1$。

## 样例输入

```
4 4
1 2
1 3
2 4
3 4
```

## 样例输出

```
2
```

## 样例解释

第 $1$ 天只能走编号 $(>1)$ 的道路，即 $2, 3, 4$ 号道路。走 $2$ 号道路从 $1$ 到 $3$。

第 $2$ 天只能走编号 $(>2)$ 的道路，即 $3, 4$ 号道路。走 $4$ 号道路从 $3$ 到 $4$。

共 $2$ 天到达。

注意如果第 $1$ 天走 $3$ 号道路到 $2$，第 $2$ 天从 $2$ 出发只能走 $3, 4$ 号道路，但 $2$ 只连接 $1$（边 $1$）和 $4$（边 $3$），走边 $3$ 可以到 $4$。所以 $1 \to 2 \to 4$ 也是 $2$ 天。

## 数据范围与提示

- 对于 $20%$ 的数据，$m \le 20$。
- 对于 $50%$ 的数据，$n, m \le 1000$。
- 对于 $100%$ 的数据，$1 \le n, m \le 2 \times 10^5$，**可能有重边和自环**。

## 题解思路

设 $dist[v]$ 为到达聚居点 $v$ 的最少天数。使用 Dijkstra 算法，按天数从小到大扩展。

当你用 $d$ 天到达 $u$ 时，下一天是第 $(d+1)$ 天，只能走编号 $> (d+1)$ 的道路。因此对于边 $e = (u, v)$，若 $e$ 的编号 $> dist[u] + 1$，则可以用 $dist[u] + 1$ 更新 $dist[v]$。

由于到达一个聚居点的天数越少，后续可走的道路越多（对边编号的限制越松），最短路径一定最优，Dijkstra 的贪心性质成立。复杂度 $O((n+m) \log n)$。

# T3 幽蓝边界

**难度：提高+/省选-**

## 题目背景

幽蓝边界是一道守护世界的树形结界。结界的每一条边都蕴含着能量，而两点之间的"幽蓝距离"决定了能量传递的损耗。

## 题目描述

有一棵 $n$ 个节点的树，每条边有一个能量值 $w_i$。

定义两个节点 $u, v$ 之间的**幽蓝距离**为：它们路径上的边数乘以路径上最大的能量值。即若 $u$ 到 $v$ 的路径经过 $k$ 条边，最大能量值为 $W$，则幽蓝距离为 $k \times W$。

请求出所有无序点对 $(u, v)$（$u < v$）的幽蓝距离之和，答案对 $998244353$ 取模。

## 输入格式

第一行一个整数 $n$。

接下来 $n-1$ 行，每行三个整数 $u, v, w$，表示一条连接 $u$ 和 $v$ 的边，能量值为 $w$。

## 输出格式

一个整数，表示所有点对幽蓝距离之和对 $998244353$ 取模的结果。

## 样例输入

```
4
1 2 3
2 3 1
2 4 2
```

## 样例输出

```
28
```

## 样例解释

所有点对的幽蓝距离：

- $(1,2)$：边数 $1$，最大 $3$，距离 $3$
- $(1,3)$：路径 $1-2-3$，边数 $2$，最大 $3$，距离 $6$
- $(1,4)$：路径 $1-2-4$，边数 $2$，最大 $3$，距离 $6$
- $(2,3)$：边数 $1$，最大 $1$，距离 $1$
- $(2,4)$：边数 $1$，最大 $2$，距离 $2$
- $(3, 4)$：路径 $3-2-4$，边数 $2$，最大 $2$，距离 $4$

总和 $3+6+6+1+2+4 = 22$。

## 数据范围与提示

- 对于 $20%$ 的数据，$n \le 300$。
- 对于 $50%$ 的数据，$n \le 3000$。
- 对于 $100%$ 的数据，$1 \le n \le 2 \times 10^5$，$1 \le w_i \le 10^9$。

## 题解思路

使用 **Kruskal 重构树**：

将所有边按能量值从小到大排序，依次加入。每条边 $(u, v, w)$ 创建一个新的内部节点 $x$，权值为 $w$，将 $u$ 和 $v$ 所在连通块的根作为 $x$ 的左右儿子。最终得到一棵有 $2n-1$ 个节点的二叉树，原节点为叶子。

重构树有两个关键性质：

1. 两个叶子的 LCA 的权值，等于原树中两点路径上的最大边权。
2. 原树中两点的距离（边数）等于重构树中两叶子距离的一半。

对每个内部节点 $x$（权值 $w$），其左右子树中的所有叶子点对的 LCA 都是 $x$。设左子树有 $s_1$ 个叶子、深度和为 $sum_1$，右子树有 $s_2$ 个叶子、深度和为 $sum_2$，则这些点对的幽蓝距离之和为：

$$w \times \frac{s_2 \cdot sum_1 + s_1 \cdot sum_2 - 2 \cdot s_1 \cdot s_2 \cdot depth[x]}{2}$$

一次后序 DFS 维护每个节点的子树叶子数和深度和，累加所有内部节点的贡献即可。复杂度 $O(n \log n)$。

# T4 管道迷宫

**难度：省选/NOI-**

## 题目背景

你被困在一个错综复杂的管道迷宫中。迷宫的每一段管道都可以旋转，但旋转需要耗费能量。你必须经过所有关键阀门，才能打开出口逃离。

## 题目描述

迷宫是一个 $n$ 行 $m$ 列的网格，每个格子是一段管道，类型如下：

- `|`：竖直直管，上下两端开口。
- `-`：水平直管，左右两端开口。
- `+`：十字管，四端都有开口。
- `.`：空格，没有管道，无法通行。

你可以旋转 `|` 和 `-` 类型的管道，将竖直变为水平或水平变为竖直，每次旋转消耗 $1$ 点能量。`+` 和 `.` 无法旋转。

起点在左上角 $(1,1)$，终点在右下角 $(n, m)$，它们都是 `+` 类型。迷宫中有 $k$ 个关键阀门，也都是 `+` 类型。

你需要从起点出发，经过所有 $k$ 个关键阀门（顺序任意），最终到达终点。移动规则是：你只能在有管道的格子中移动，且相邻两个格子必须有相对的开口（例如从左边格子向右走，左边格子需要有右开口，右边格子需要有左开口）。

经过一个格子时，入口和出口方向必须都有开口。如果当前管道类型不满足，可以旋转它（仅 `|` 和 `-` 可旋转，且旋转后仍然只有两个开口）。每个格子在路径中最多经过一次。

求完成旅程所需的最少能量，若无法完成输出 $-1$。

## 输入格式

第一行三个整数 $n, m, k$。

接下来 $n$ 行，每行一个长度为 $m$ 的字符串，表示迷宫。

接下来 $k$ 行，每行两个整数 $x, y$，表示关键阀门的坐标（保证是 `+` 类型，且不是起点和终点）。

## 输出格式

一个整数，表示最少能量；无法完成输出 $-1$。

## 样例输入 1

```
2 2 0
+|
|-
```

## 样例输出 1

```
1
```

## 样例解释 1

最优路径为 $(1,1) \to (2,1) \to (2,2)$。$(2,1)$ 是 `|` 型管道，从上方进入后需向右走出，必须旋转为 `-` 型，花费 $1$ 点能量。

------

## 样例输入 2

```
2 4 1
+|++
++|+
2 1
```

## 样例输出 2

```
1
```

## 样例解释 2

必须经过关键阀门 $(2,1)$。最优路径为 $(1,1) \to (2,1) \to (2,2) \to (2,3) \to (2,4)$。其中 $((2,3))$ 是 `|` 型管道，要水平通过需旋转为 `-` 型，花费 $1$ 点能量。

## 数据范围与提示

- 对于 $15\%$ 的数据，$k = 0$
- 对于 $40\%$ 的数据，$n, m \le 50$，$k \le 5$。
- 对于 $70\%$ 的数据，$n, m \le 200$，$k \le 10$。
- 对于 $100\%$ 的数据，$1 \le n, m \le 500$，$0 \le k \le 15$，保证起点和终点是 `+` 类型，关键阀门互不相同且不是起点终点。

## 题解思路

本题分为两步：

**第一步：多点最短路。** 对每个关键点（起点、终点、$k$ 个阀门，共 $(k+2)$ 个）做一次 0-1 BFS，求出它到其他所有关键点的最小旋转花费。

BFS 的状态为 $(x, y, d)$，表示到达格子 $((x, y))$ 且从方向 $d$ 进入该格。转移时枚举出口方向，根据当前格子的管道类型判断是否需要旋转（`|` 和 `-` 只能支持入口、出口在同一直线，若类型不匹配则旋转花费 $1$；`+` 任意方向均可，花费 $0$；`.` 不可通行）。由于边权只有 $0$ 和 $1$，用双端队列 0-1 BFS，复杂度 $(O(nm))$。

**第二步：状压 DP。** 将 $(k+2)$ 个关键点编号，设 $(dp[mask][i])$ 表示已经经过的关键点集合为 $mask$、当前在第 $i$ 个关键点时的最小花费。转移枚举下一个未经过的关键点 $j$，用第一步预处理的距离更新。最终答案为 $dp[全集合][终点]$。

总复杂度 $O(k \cdot n \cdot m + 2^k \cdot k^2)$，在数据范围内可通过。

# T5 霓虹灯牌

**难度：省选/NOI‑**

## 题目背景

夜幕降临，城市中林立着大量霓虹灯牌。每一块灯牌由若干灯管组成，灯管可以切换亮灭状态。但老旧的线路会带来连锁效应，修改一处会带动一批灯管同步变化。你需要操控灯牌，完成指定的显示图案。

## 题目描述

给定 $n$ 个灯管，编号 $1\sim n$，每个灯管有状态 $0$（熄灭）、$1$（点亮）。 存在 $m$ 组控制关系，每组控制关系形如 $(L,R,w)$：选择激活该控制，会将区间 $[L,R]$ 内所有灯管状态异或 $w$（$w\in{0,1}$），激活一次消耗代价 $w$。同一组控制可以被激活任意次；激活偶数次等价于未激活，奇数次等价于激活一次。

初始所有灯管状态为 $0$。给定目标数组 $a_1,a_2,\dots,a_n$，求通过选择若干控制关系，使得灯管最终状态等于目标数组的**最小总代价**。无解输出 $-1$。

### 部分分

- Subtask1(15pts): $n\le 10,m\le 10$
- Subtask2(25pts): $(w=1)$ 对所有控制，$(n,m)\le 5000$。
- Subtask3(30pts): $(n,m)\le 5\times 10^4$。
- Subtask4(30pts): $1\le (n,m) \le 2\times 10^5$。

## 输入格式

第一行两个整数 $(n,m)$。 第二行 $n$ 个整数 $a_1\cdots a_n$，表示目标状态。 接下来 $m$ 行每行三个整数 $(L,R,w)$，描述一组控制关系。

## 输出格式

输出最小代价；无解输出 $-1$。

## 样例输入

```
5 3
1 0 1 1 0
1 3 1
3 5 1
2 4 0
```

## 样例输出

```
1
```

## 样例解释

选取第 $1$ 组控制 $(1,3,1)$，代价为 $1$。 异或后：位置 $(1,2,3)$ 翻转，得到 $[1,1,1,0,0]$。 再选取第 $3$ 组控制 $(2,4,0)$，代价 $0$，区间异或 $0$，等价于只翻转位置 $(2,4)$。 最终得到 $[1,0,1,1,0]$，达成目标，总代价 $1$。

## 简要题解

把区间异或转化为差分：设差分 $d_1=a_1,\ d_i=a_i\oplus a_{i-1}\ (i>1),d_{(n+1)}=a_n$。 控制 $(((L,R,w)))$ 等价于差分点 $L$、$(R+1)$ 同时异或 $w$，代价 $w$。 问题转化：有 $(n+1)$ 个点，每条边连接 $L,(R+1)$，边权 $w$；可以选边，选则两端点异或 $w$，付出代价 $w$。要求把初始全0的差分变成目标差分 $d$，求最小代价。 这是带权并查集维护异或约束的最小生成树模型。对每个连通块，判断目标差分是否可以实现；可实现则统计连通块内最小代价。复杂度 $O((n+m)\alpha(n))$。

# T6 时钟链接

**难度：NOI/NOI+/CTS**

## 题目背景

> 参考 Phigros *Clock Paradox* 歌单：时间循环、时序悖论、多条时间线互相干涉。

在时间迷宫中存在 $n$ 座时钟，每座时钟拥有一个循环周期 $p_i$。时钟的读数永远在 $[0,p_i-1]$ 循环。 存在 $m$ 条**时间链接**，每条链接约束两座时钟的读数关系。但时间悖论会产生冲突；你可以破坏部分链接来规避悖论。你的任务是保留若干链接，使得整个系统无悖论，并且最大化保留链接的权值总和。

## 题目描述

有 $n$ 个时钟，第 $i$ 个时钟周期为正整数 $p_i$。 第 $j$ 条时间链接 $(u_j,v_j,c_j,w_j)$，含义：若保留这条链接，则必须满足： $$x_{u_j} \equiv x_{v_j} + c_j \pmod{\gcd(p_{u_j},p_{v_j})}$$ $x_i$ 代表时钟 $i$ 的读数。保留该链接获得权值 $w_j$；删掉则得不到该权值。

选出一个链接子集，满足子集中所有约束可以同时被满足（存在一组 $x_1,x_2,\dots,x_n$ 满足全部约束），求子集权值总和的最大值。

## 输入格式

第一行 $(n,m)$。 第二行 $n$ 个整数 $p_1,p_2,\dots,p_n$。 接下来 $m$ 行，每行四个整数 $u_j,v_j,c_j,w_j$。

## 输出格式

输出最大可获得权值和。

## 部分分

- Subtask1(8pts): $n\le 8,m\le 20$，子集枚举。
- Subtask2(16pts): 全部 $p_i$ 为质数，$(n,m)\le 1000$。
- Subtask3(24pts): $(n,m)\le 5000$。
- Subtask4(52pts): $1\le n\le 10^5,1\le m\le 2\times 10^5$，$1\le p_i\le 10^9$，$0\le c_j < \gcd(p_{u_j},p_{v_j})$，$1\le w_j\le 10^9$。

## 样例输入

```
3 3
4 6 8
1 2 1 10
2 3 2 20
1 3 0 15
```

## 样例输出

```
30
```

## 样例解释

$\gcd(4,6)=2$，第一条约束 $x_1 \equiv x_2+1 \pmod 2$。 

$\gcd(6,8)=2$，第二条约束 $x_2\equiv x_3+2 \pmod 2 \Rightarrow x_2\equiv x_3 \pmod 2$。 

$\gcd(4,8)=4$，第三条约束 $x_1\equiv x_3 \pmod 4$。

若同时选 $1,2,3$：由 $1,2$ 得 $x_1 \equiv x_3+1 \pmod 2$；第三条要求 $x_1\equiv x_3 \pmod4$，推出 $x_1\equiv x_3 \pmod2$，发生矛盾。 最优方案选取链接 $1,2$，总权值 $10+20=30$，约束相容，无时间悖论。

## 简要题解

这是**带权并查集维护模意义下偏移（扩展域并查集 / 种类并查集的广义版本），求最大权无矛盾约束子集**，等价于最大权生成问题：把约束视为边，优先选权大的边，使用可维护同余偏移的带权并查集，依次加入边；若加入后不产生矛盾则保留，累加权值；矛盾则丢弃。

关键难点：每条约束的模数不是全局固定，是 $\gcd(p_u,p_v)$；并查集维护 $(dis[x])$ 表示 $x$ 相对于根的偏移，合并的时候要做模 $\gcd(p_{root_u},p_{root_v})$ 的相容性校验。

> 注意：普通种类并查集只适用于固定模数；本题每个连通块内部模数随合并动态变化，需要处理同余方程组相容性，是本题黑题核心卡点。总复杂度 $O(m\log m + (n+m)\alpha(n))$。
